# Лабораторная работа: мини-макс с альфа-бета отсечением

## 1. Цель работы

Изучить алгоритм мини-макс и его оптимизацию с помощью альфа-бета отсечения, реализовать оба алгоритма рекурсивно для игрового дерева глубиной 6 и сравнить их эффективность по числу проверенных узлов и времени выполнения.

## 2. Теоретические сведения

**Мини-макс** применяется в антагонистических играх двух игроков. Игрок MAX стремится получить наибольшую оценку, игрок MIN наименьшую. Значения листьев (оценки конечных позиций) поднимаются вверх по дереву: на уровнях MAX выбирается максимум из значений потомков, на уровнях MIN минимум. Значение корня показывает лучший результат, которого MAX может добиться при оптимальной игре соперника. Недостаток алгоритма: он обходит все узлы дерева, а их число растёт экспоненциально (для ширины `b` и глубины `d` это порядка `b^d`).

**Альфа-бета отсечение** даёт тот же результат, но пропускает ветви, которые заведомо не влияют на итог. Для этого при обходе передаются два параметра:

- `alpha` — лучшее значение, которое MAX уже гарантированно может получить на пути к корню;
- `beta` — лучшее значение, которое MIN уже гарантированно может получить на пути к корню.

Если в какой-то момент `alpha >= beta`, оставшиеся потомки текущего узла можно не проверять: соперник не допустит попадания в эту ветвь. Эффективность отсечения зависит от порядка обхода: чем раньше рассматриваются сильные ходы, тем больше ветвей отсекается.

## 3. Условия

| Параметр | Значение |
|---|---|
| Глубина дерева | 6 |
| Ширина дерева | 2 (бинарное дерево) |
| Игроки | MAX (ходит в корне) и MIN, уровни чередуются |
| Листья | случайные целые числа от -10 до 10, генерируются через `random.randint` |
| Реализация | рекурсивная, дерево хранится во вложенных списках |
| Метрики сравнения | число проверенных узлов, время выполнения |

Полное дерево содержит 2^6 = 64 листа и 127 узлов в сумме (1 + 2 + 4 + 8 + 16 + 32 + 64).

## 4. Описание программы

- `create_tree(depth)` рекурсивно строит дерево: на глубине 0 возвращает случайное число (лист), иначе список из `WIDTH` поддеревьев.
- `minimax(node, maximizing)` обычный мини-макс. Если узел не список, это лист, и возвращается его значение. Иначе вычисляются значения всех потомков и берётся `max` или `min` в зависимости от игрока.
- `alpha_beta(node, alpha, beta, maximizing)` мини-макс с отсечением. Потомки перебираются по одному, после каждого обновляются `alpha` (для MAX) или `beta` (для MIN), и при `alpha >= beta` цикл прерывается командой `break`.
- Глобальные счётчики `minimax_nodes` и `alpha_beta_nodes` увеличиваются при каждом входе в функцию, то есть считают все посещённые узлы, включая листья.
- Время измеряется через `time.perf_counter()`. Оба алгоритма запускаются на одном и том же дереве, что делает сравнение честным.

## 5. Код

```python
import random
import time

DEPTH = 6
WIDTH = 2

minimax_nodes = 0
alpha_beta_nodes = 0


def create_tree(depth):
    if depth == 0:
        return random.randint(-10, 10)

    return [create_tree(depth - 1) for _ in range(WIDTH)]


def minimax(node, maximizing):
    global minimax_nodes
    minimax_nodes += 1

    if not isinstance(node, list):
        return node

    values = [minimax(child, not maximizing) for child in node]

    if maximizing:
        return max(values)
    else:
        return min(values)


def alpha_beta(node, alpha, beta, maximizing):
    global alpha_beta_nodes
    alpha_beta_nodes += 1

    if not isinstance(node, list):
        return node

    if maximizing:
        result = -float("inf")

        for child in node:
            result = max(
                result,
                alpha_beta(child, alpha, beta, False)
            )

            alpha = max(alpha, result)

            if alpha >= beta:
                break

        return result

    else:
        result = float("inf")

        for child in node:
            result = min(
                result,
                alpha_beta(child, alpha, beta, True)
            )

            beta = min(beta, result)

            if alpha >= beta:
                break

        return result


tree = create_tree(DEPTH)


start = time.perf_counter()
minimax_result = minimax(tree, True)
minimax_time = time.perf_counter() - start


start = time.perf_counter()
alpha_beta_result = alpha_beta(
    tree,
    -float("inf"),
    float("inf"),
    True
)
alpha_beta_time = time.perf_counter() - start


print("MINIMAX + ALPHA-BETA")

print("\nГлубина дерева:", DEPTH)
print("Ширина дерева:", WIDTH)

print("\nMINIMAX:")
print("Результат:", minimax_result)
print("Проверено узлов:", minimax_nodes)
print("Время:", minimax_time)

print("\nALPHA-BETA:")
print("Результат:", alpha_beta_result)
print("Проверено узлов:", alpha_beta_nodes)
print("Время:", alpha_beta_time)

print("\nСравнение:")
print("Экономия узлов:", minimax_nodes - alpha_beta_nodes)
```

## 7. Анализ результатов

- **Корректность.** Оба алгоритма вернули одинаковое значение, значит, отсечение не искажает результат, а лишь убирает лишнюю работу.
- **Число узлов.** У мини-макс оно фиксировано (127) и не зависит от значений листьев. У альфа-бета оно зависит от того, в каком порядке расположены значения: при случайной генерации оно меняется от запуска к запуску, но никогда не превышает 127.
- **Время.** В этом запуске альфа-бета оказалась чуть медленнее, хотя проверила меньше узлов. Причина в размере задачи: на 127 узлах всё выполняется за десятки микросекунд, а на каждом шаге альфа-бета дополнительно обновляет `alpha`/`beta` и сравнивает их, что сравнимо с выигрышем от отсечения. К тому же единичный замер такой длительности сильно зависит от случайных задержек системы.
- **Масштабирование.** Экономия числа узлов растёт с глубиной и шириной дерева. В лучшем случае (сильные ходы рассматриваются первыми) альфа-бета проверяет порядка `b^(d/2)` узлов вместо `b^d`, то есть позволяет искать примерно вдвое глубже за то же время.

## 8. Вывод

В работе реализованы рекурсивные алгоритмы мини-макс и мини-макс с альфа-бета отсечением для дерева глубиной 6 и шириной 2 со случайными листьями. Оба алгоритма дают одинаковый результат, но альфа-бета проверяет заметно меньше узлов (78 против 127 в данном запуске, экономия около 38,6%). Выигрыш по времени на таком небольшом дереве не проявился из-за накладных расходов и погрешности измерений, однако с ростом глубины и ширины дерева преимущество альфа-бета становится существенным. Эффективность отсечения зависит от порядка обхода ветвей, поэтому на практике перед поиском ходы упорядочивают по предполагаемой силе.
