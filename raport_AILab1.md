# Отчёт по лабораторной работе №1
## Тема: Построение конечного автомата и программы для распознавания языка

### Вариант задания

Язык: **(ab)ⁿ(cd)ᵐ, n ≥ 1, m ≥ 0**

Строка принадлежит языку, если она состоит из одного или более повторений блока `ab`, за которым может следовать ноль или более повторений блока `cd`.

---

### 1. Диаграмма конечного автомата

Автомат состоит из состояний, соответствующих последовательному чтению символов `a`, `b`, `c`, `d`. Двойным кругом отмечено состояние после первого блока `ab` — уже допускающее (так как m может быть равно 0). Дальнейшие переходы по `c` и `d` позволяют распознавать дополнительные блоки `cd`.

![Диаграмма автомата](image.png)

---

### 2. Программная реализация

Программа на Python эмулирует работу автомата: сначала подсчитывает количество блоков `ab`, затем — блоков `cd`, после чего проверяет, что строка обработана полностью и найден хотя бы один блок `ab`.

```python
def check_string(s):
    i = 0
    n = 0
    m = 0

    # Проверяем блоки "ab"
    while i + 1 < len(s) and s[i:i + 2] == "ab":
        n += 1
        i += 2

    # Проверяем блоки "cd"
    while i + 1 < len(s) and s[i:i + 2] == "cd":
        m += 1
        i += 2

    # Проверяем условия n >= 1
    # и полную обработку строки
    if n >= 1 and i == len(s):
        return True
    else:
        return False


while True:
    s = input("Введите строку: ")

    if s == "0":
        print("Программа завершена.")
        break

    if check_string(s):
        print("Строка принадлежит языку.")
    else:
        print("Строка не принадлежит языку.")
```
